About Perlin Atelier

A standalone, offline generative-art sketchbook inspired by experiments in mathematical pen plotting. It uses a seeded 2D gradient Perlin-noise function and fractal Brownian motion to produce repeatable drawings.

Letter garden: Foundation → Grow → Break → Write → Decorate. Uses independent geometry and a purpose-drawn stroke alphabet.

Other styles: drifting lines, flow-field streamlines, connected topographic contours and organic orbits. Exported SVGs use physical millimetre dimensions and one named layer per pen colour. Letters are pen strokes, ready to plot without installed fonts.

Plotter note: select a single-pen palette for uncomplicated plotting, or use separate colour passes. Preview colours are suggestions, not calibrated ink measurements. This app does not simulate contact bounce, motor movement, or real ink laydown.

Privacy: all generation happens in this browser. No account, network connection or uploads are required.
